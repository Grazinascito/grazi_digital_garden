### parametros de inferencia, embedds,

COMO

existe uma mecanica na forma que o modelo seleciona as palavras exatas para montar uma sentença, é assim que ele adivinha qual a proxima palavra que deve escrever. A mecanica funciona assim:  A partir do input recebido, o modelo cria uma rede semantica chamado de embedds que organiza o token(palavra) em uma especie de grafo calculando o grau de proximidade entre as palavras, além disso, também é criado um vetor com algumas possibilidades de palavras, cada uma tem uma porcentagem especifica, ex: Bob is a ___ → [cat, animal, dog, human]

a partir disso, os parametros de inferencia atuam como reguladores de distribuicao probabilistica.

Temos 3 parametros principais A temperatura que se aumentada, aumenta a possibilidade do modelo selecionar mais opcoes de palavras diversas, util para brainstorms, geração de ideias, pensamento fora da caixa, porem o tradeoff é que o modelo fica mais sucetivel a alucinações e inconsistencias
